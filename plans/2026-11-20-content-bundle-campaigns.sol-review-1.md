## Verdict

**Not ready to turn into issues.** At `origin/main` (`5a5f016`), the campaign loop has one slot, one draft post, and one destination per unit of work. The plan assumes it can add cross-brand evidence, multiple deliveries, and selective regeneration while preserving that loop’s behavior. The code makes those changes inseparable from cohesion, series review, and publication approval. Settle the piece and delivery boundary, campaign-scoped source access, and the reviewed outbound payload before filing implementation issues. M1 can be a useful tracer after it is narrowed. This review verified the checked-out source and published platform limits. Live account mappings, provider access, and the FreshProof renderer contract remain unverified.

## Blocking findings

1. **§4.5–4.6, §4.9, CB-05/15/17 — Fan-out changes what the campaign loop operates on.** Both draft generators write one `v2Post` per slot before cohesion. Cohesion resolves each post back to its slot, so a mirrored pillar appears as two pillars, and a shared script appears to have repeated openings. Cohesion can also add a placeholder CTA and rewrite copy after composition. The calendar step schedules existing posts and creates intents. On a partially materialized retry it can reset approvals and dates across the batch. Keep slots as the piece record, give deliveries stable identities, run cohesion over canonical piece revisions, and materialize delivery posts idempotently. For bundle plans, make cohesion report defects for correction or send any corrections through the same drafting and validation path. [Mock generation](convex/draftSet.ts:118), [live generation](convex/draftGeneration.ts:226), [cohesion inputs and fixes](convex/cohesion.ts:42), [calendar materialization](convex/queue.ts:165)

2. **§4.5, §4.7, A3, CB-04/15 — A lead-brand corpus would enter the existing brand-wide source pool.** `listCorpora` and `getCorpus` authorize by brand membership. `attachCorpus` accepts any same-brand corpus, and `getCampaignSession` resolves idea citations into raw `excerpt.text` without checking that the cited corpus is attached. Meanwhile, series review hides cited text when the corpus belongs to a different brand from the series. Adding `scrubbedText` alongside `text` leaves all these readers in place. Give bundle sources campaign-scoped visibility and use one resolver that checks the active principal, campaign, pinned source version, excerpt eligibility, and delivery brand. Exclude bundle corpora from legacy browse and attachment unless explicitly shared. Store sanitized evidence by default and define separate restricted storage if original bytes are required. Scrub or reject sensitive material in manifest metadata, titles, angles, decision text, provenance labels, filenames, and source content before model dispatch or display. [Corpus reads](convex/corpora.ts:323), [corpus attachment](convex/campaigns.ts:124), [citation hydration](convex/campaigns.ts:542), [series evidence display](convex/seriesReview.ts:281), [live prompt input](convex/draftGeneration.ts:118)

3. **§4.4, Q4, CB-03/04 — The ingest principal and commit authority are underspecified.** The lab-import route uses a deployment-wide admin credential and type casts. Its rate limiter is a process-local map keyed by forwarded IP, and throttled requests still attempt an audit write. `requireBrandAccess` proves membership and admits viewers. Convex callers also need their own checks because the Clerk proxy governs Next.js routes. Use a dedicated Convex HTTP action invoking a fixed internal mutation, with no deploy key in the new route, or specify an equivalently narrow bridge. Recheck the token’s expiry, revocation, scope, and current editor access to the lead, piece, and delivery brands in the write transaction. Cover user disablement, status reads, re-pushes to existing keys, and direct calls to legacy accept, draft, and approval functions. Use high-entropy expiring tokens and shared quotas before expensive parsing, with trusted ingress identity, per-token and per-owner quotas, and bounded rejection logging. Define “dry run writes nothing” as no product-state writes and explicitly allow rate-limit and audit accounting. [Lab-import auth and limiter](app/api/ops/lab-import/route.ts:9), [lab-import request path](app/api/ops/lab-import/route.ts:91), [brand access](convex/campaignAccess.ts:18), [existing route exemptions](proxy.ts:5), [Convex internal functions](https://docs.convex.dev/functions/internal-functions)

4. **§4.3, §4.5, A6, CB-04/11 — Re-push needs a revision and concurrency contract.** A content fingerprint alone leaves a delayed retry of version A ambiguous after version B has committed. The current generator allows one set per shape and records the full allowed citation list on each draft, so comparing those lists will flag pieces that never used the changed fact. Calendar re-entry is unsafe for a mixed batch of approved and regenerated posts. Require a request idempotency key plus an expected base version, resolve exact retries transactionally, and reject conflicting or stale writes. Pin the accepted plan and each draft revision to its source, decisions, and voice versions. Use actual claim bindings to compute impact. Preserve operator edits by stable piece key and field, surface conflicts and deletions, and put newer-source notices for approved or published pieces in a separate impact record. Test concurrent first pushes, A → B → delayed retry of A, approval racing regeneration, and rescheduling a mixed batch. [One-set guard](convex/draftGeneration.ts:193), [stored citation set](convex/draftGeneration.ts:330), [queue retry behavior](convex/queue.ts:170)

5. **§4.7, CB-09/10/13/21/22 — The tracing rule rejects valid copy and accepts unsupported claims.** A value can occur in the source for a different vendor, denominator, or unit. A three-word attributed quote escapes the gate, and a factual claim about the current year escapes by default. Citation IDs and URLs add digits with no factual meaning. The existing CSV extractor retains column names and a row count, so it cannot trace a data value at all. Require claim-level bindings to a pinned passage or typed row and column, including entity, measure, unit, and relevant population or timeframe. Check every attributed direct quote, with exact-span matching after typography normalization, and classify structural tokens from parsed fields. Allow declared, reproducible derivations with inputs, formula, and rounding policy. Attestation should confirm that evidence or derivation. Bind the result to the reviewed revision and apply it after cohesion, edits, link assembly, and structured rendering, through the shared approval path used by both composer and batch review. Give failed pieces a reviewable state and budget retry and regeneration calls before dispatch. [CSV/JSON extraction](lib/corpusExtract.ts:166), [citation validation](lib/campaignDrafting.ts:220), [cohesion edits](convex/cohesion.ts:153), [editorial approval](convex/publishing.ts:997), [batch approval](convex/seriesReview.ts:529)

6. **§4.7, CB-01 — Stripping only at dispatch breaks the exact-copy review contract.** Buffer status refresh compares the stored attempt snapshot with assembled copy and the trimmed first comment. Sanitizing only in the adapter leaves a mismatched receipt or a snapshot that describes different bytes from those sent. For blogs, early stripping can break figure validation bound to the original content, while late stripping can change the expected file bytes on an existing export branch. Preserve the stored editorial fingerprint and pin a separate, versioned rendered-payload hash for approval review, dispatch, and reconciliation. Keep evidence off the publishable body where possible. Audit guard failures before remote writes and put old in-flight attempts on an explicit compatibility path. Check final body, first comment, hashtags, frontmatter, PR title and body, filenames, captions, alt text, SVG text, and ZIP contents. Include GitHub reschedule writes, both blog entry points, Buffer batch and single submit, and future manual exports. The Zernio validation script also needs an explicit scope decision if “every outbound path” covers repository tooling. [Buffer assembly](convex/publishing.ts:2182), [Buffer receipt matching](convex/bufferDelivery.ts:16), [series preview](convex/seriesReview.ts:205), [figure binding](lib/github.ts:456), [PR branch reconciliation](lib/github.ts:608), [GitHub reschedule](convex/githubPrSync.ts:31), [Zernio validation script](scripts/zernio-live-validation.mjs:88)

7. **§4.6, §4.9–4.10, CB-16–20 — Separate manual delivery from provider dispatch, and model dependencies by delivery.** Buffer eligibility checks LinkedIn channel, account mapping, and post state. A manual LinkedIn Article on a mapped account can reach the provider path unless mode and format are checked server-side. Article holds currently require a same-brand `corvo-blog` parent and a current publication receipt, so a FreshProof promo targeting a Personal LinkedIn Article will fail. Use a manual delivery state with an export receipt and a human-recorded publication receipt. Pin the mirror to an approved parent revision and a separately approved destination. Enforce server-side body immutability, download authorization, and safe URL correction. A URL correction must stale dependent copy and review receipts and surface already-dispatched dependents. Choose the Article delivery when the plan contains one and wait for its live URL. Use the blog fallback when the plan contains no Article delivery. [Provider adapter contract](lib/providerAdapters.ts:64), [Buffer eligibility](convex/publishing.ts:2020), [current companion hold](convex/articleDependencies.ts:36), [same-brand attachment](convex/articleDependencies.ts:265), [storage access precedent](convex/v2Storage.ts:63)

8. **§4.3–4.5, §10 risk 5, CB-02/04 — The upload cap does not bound Convex work.** A 250 KB manifest can fit in one document. A file at the 1 MB boundary cannot safely share a document with metadata, and the excerpt splitter can retain a single overlong chunk. Many small excerpts and repeated citation arrays can exceed transaction or query limits on an otherwise valid push. Convex caps documents at 1 MiB, arrays at 8,192 entries, transaction reads and writes at 16 MiB each, writes at 16,000 documents, and index ranges read at 4,096. The current series bridge caps a batch at 100 posts. Set measured limits for serialized bytes, excerpts, pieces, deliveries, per-piece evidence, expansion, and prompt tokens. Bound the encoded HTTP body before parsing, including JSON overhead. Store large sanitized source artifacts outside database documents. If the worst accepted fixture requires staged writes, keep partial versions invisible until an atomic finalize and include cleanup and retry semantics. Add compound indexes for token lookup, owner/key, bundle/version, stable piece and delivery keys, and source bindings. Specify runtime argument, return, and table validators plus legacy defaults. [Excerpt splitter](lib/corpusExtract.ts:53), [corpus write loop](convex/corpora.ts:129), [draft citation lookups](convex/draftGeneration.ts:96), [series cap](convex/campaignSeries.ts:26), [Convex limits](https://docs.convex.dev/production/state/limits), [Vercel body limits](https://vercel.com/docs/functions/limitations)

## Answers to 2a–2h

**2a.** Extend `campaignSlots` with piece-level metadata and keep a separate delivery record. A parallel `campaignPieces` model would duplicate the existing shape, ordering, and slot references. A delivery array can describe a bounded proposal, but operational delivery state needs a stable key, pinned revision, and independent schedule, approval, and receipt. Cohesion should see the canonical piece once. [Slot schema](convex/schema.ts:844), [cohesion inputs](convex/cohesion.ts:42)

**2b.** Keep one corpus with the lead brand recorded as provenance. Grant access through the owning campaign and its authorized delivery brands. The citation URI can retain the corpus’s brand. Its parser does no authorization, and the current generation check compares the corpus to the campaign lead, so drafting can work while non-lead series review still loses evidence. Queue intents currently inherit the campaign brand, Buffer uses the post brand, and GitHub uses a single configured destination. Each of those boundaries needs an explicit delivery-brand rule. [Citation parser](lib/campaignGrounding.ts:46), [queue intent creation](convex/queue.ts:200), [Buffer destination lookup](convex/publishing.ts:2063), [GitHub destination](lib/github.ts:6)

**2c.** A high-entropy hashed bearer token is suitable for proposing bundles if it has bounded authority and a finite lifetime. Authorize each operation against the token and current membership, including which existing bundles it can read or revise. Scope status to minimal metadata. Authenticate before reading a large request, apply distributed quotas, and make the final write recheck authority and revision together. The lab-import pattern is evidence of an existing bridge, with a materially broader credential and weaker rate limiting than this feature calls for. [Lab-import bridge](app/api/ops/lab-import/route.ts:14)

**2d.** Gate evidence bindings, not numeral equality. For example, `41.7%` about Exa must fail if the cited row says `41.7%` about Parallel. A rendered `42%` can pass with an explicit, reviewed rounding rule applied to the correct `41.7%` input. Exempt a timestamp in a typed script timing field and check the same value if it is claimed in voiceover. Let reference-only sources support permitted numeric claims through the verifier while excluding them from quote selection. [Current prompt and validator](lib/campaignDrafting.ts:170)

**2e.** Use a campaign-private, system-generated idea and a real `campaignIdeas` membership join as a transitional adapter if that keeps the tracer small. Avoid making these ordinary reusable inbox ideas. Store bounded, resolved evidence bindings and keep legacy idea removal and relinking from silently breaking accepted bundle pieces. With auto-generated ideas, a linked `ideaId` is trivial to satisfy, so acceptance must also check usable evidence and valid destinations. [Working-set model](convex/schema.ts:830), [slot completeness](lib/campaignShapes.ts:117), [idea removal](convex/campaigns.ts:343)

**2f.** Reuse editorial approval and audit for manual delivery. Keep export and human confirmation outside the provider adapter contract. A delivery may expose `awaiting-manual-publish` to the UI, provided all dispatch, edit, retry, and calendar paths understand it. Bind a mirror export to both the exact source revision and the approved destination. Record export and publication as separate events, with the latter explicitly human-reported. [Provider adapter](lib/providerAdapters.ts:47), [post status transitions](convex/publishing.ts:997)

**2g.** Treat the outbound guard as a reviewed rendering boundary. Validate all public fields and rendered artifacts, including updates to existing PRs. Use one payload across preview, claims, writes, and receipt comparison. Preserve original editorial and visual signatures and separately identify rendered bytes. Define exclusions for operator-only previews and internal evidence, and enforce the prompt privacy boundary independently. [Blog editorial fingerprint](lib/blogContract.ts:17), [visual export claim](convex/visualPublication.ts:45), [Buffer release version](lib/socialPayload.ts:1)

**2h.** Start with a bounded single transaction if a maximum-size fixture proves headroom. Use indexed lookups and Convex’s transaction conflict handling for uniqueness and version allocation. Keep blob work out of the atomic boundary and finalize only complete references. Optional fields support old rows, while literal-union additions still require coordinated updates to duplicated validators, UI maps, filters, dispatch, and readers. [Schema value lists](convex/schema.ts:14), [live drafting validators](convex/draftGeneration.ts:40), [Convex transaction limits](https://docs.convex.dev/production/state/limits)
